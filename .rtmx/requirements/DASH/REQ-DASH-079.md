# REQ-DASH-079: Export Graph as PNG Image

## Summary

The graph toolbar shall include an "Export PNG" button that renders the current graph SVG
to a canvas element and downloads the result as a PNG image. The export respects the current
zoom and pan state, includes the graph title and legend, and produces a high-resolution image
suitable for embedding in presentations and documents.

## Acceptance Criteria

1. Graph toolbar contains an "Export PNG" button adjacent to the Export SVG button
2. Clicking the button downloads a file named `{project}-graph-{date}.png`
3. The PNG is generated by: serializing the SVG (using REQ-DASH-078 inline-style logic), drawing it onto an offscreen canvas via `Image` + `canvas.drawImage()`, then calling `canvas.toDataURL('image/png')`
4. The exported PNG respects the current zoom level and pan position (exports what the user sees)
5. The PNG includes the graph title at the top and legend at the bottom-right, matching the SVG export
6. The PNG resolution is 2x the display resolution (retina-quality) by default
7. A resolution dropdown allows selecting 1x, 2x, or 3x before export
8. Export of a 300-node graph at 2x resolution completes in under 5 seconds
9. If canvas rendering fails (e.g., tainted canvas from CORS), an error toast is shown via the toast system
10. The PNG has a white background (not transparent) for document embedding compatibility

## Dependencies

- REQ-DASH-078 (SVG export provides the inline-styled SVG source for canvas rendering)

## Test Strategy

- Unit test: PNG export function calls canvas.toDataURL with 'image/png'
- Unit test: canvas dimensions are 2x the SVG viewBox dimensions at default resolution
- Unit test: resolution selector changes canvas scaling factor
- Unit test: canvas rendering failure triggers error toast
- Unit test: exported PNG has white background (canvas fillRect before drawImage)
- Integration test: download triggered in browser produces a valid PNG file
- Performance test: 300-node graph at 2x resolution exports in under 5 seconds
- Edge case test: empty graph (0 nodes) produces a PNG with just the title and empty legend
